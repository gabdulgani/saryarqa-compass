# Saryarqa Compass

Trust-first, multilingual (EN/DE) hiking-trip website prototype for Saryarqa Routes, Astana, built for German independent travellers.

Features: Guide Trust Profiles, AI Trip Builder, Virtual Preview (look-around viewer, route maps, day-by-day inclusions, altitude profile), Arrival Concierge, euro checkout flow and GDPR notes.

It is a static site: open `index.html` or host the folder on any static host (GitHub Pages, Netlify, Cloudflare Pages).

Guide profiles, reviews, prices and dates are sample content for the case study.
